# Bini Teklehaimanot – Modular Resume Portfolio

Welcome to my modular resume repository. I maintain tailored resume variants for strategic outreach, job applications, and branding. Each resume is assembled from reusable Markdown blocks, making it easy to update, customize, and share across roles and audiences.

## 🧱 Structure

- `shared/` – Static blocks reused across all resumes (header, education, certifications)
- `TPM-AI-Compliance/` – Resume for Technical Program Manager roles focused on AI, compliance, and governance
- `Staff-Data-Scientist/` – Resume for Staff Data Scientist roles focused on modeling, experimentation, and infrastructure

Each variant folder contains:
- `modules/` – Role-specific blocks (summary, skills, experience)
- `resume.md` – Full resume assembled from shared + role-specific modules
- `resume-no-summary.md` – Alternate version without summary for ATS or internal referrals
- `README.md` – Overview of the variant and its strategic focus
